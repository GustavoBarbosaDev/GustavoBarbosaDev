### Sobre Mim

Sou desenvolvedor backend júnior e trabalho com APIs REST em Python. Comecei na Física (UFPI), cheguei à programação por uma pesquisa sobre teoria do caos e hoje curso Engenharia de Software.

No dia a dia uso FastAPI, SQLModel e PostgreSQL, com pytest e GitHub Actions para testes e CI. Me interesso principalmente por autenticação, testes e deploy. O [Socialink](https://github.com/GustavoBarbosaDev/socialink) é o projeto onde apliquei isso de ponta a ponta, e os detalhes estão no [portfólio](https://portifolio-tau-umber-38.vercel.app/).
